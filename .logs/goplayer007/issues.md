# Åpne punkter

Gjeldende åpne punkter etter [retting og dokumentert egenutprøving](994-2026-10-29-20-26-15-ajour-egenutproving-og-mengdetesting.md), oppdatert 2026-11-01 etter prosjekteierens sluttbekreftelse. De konkrete omprøvingene er bestått som **egenutprøving utført av prosjekteier**; tekniske prøver føres separat. [Leveringsoversikten](../../README.md#leveringsoversikt--1-november-2026) og [samlede begrensninger med V1-betydning](../../studieplanlegger/README.md#kjente-begrensninger-ved-levering) er gjeldende innganger. Eldre loggseksjoner bevarer statusen på sine tidspunkter.

Sluttrapporten er innarbeidet bare som Markdown etter prosjekteierens senere ønske; Manrope-fontnavnene er rettet til TrueType. Se [Sluttrapport og leveringskontroll med datert oppfølging](993-2026-11-01-22-34-20-ajour-sluttleveranse.md). Ingen nye produktpunkter følger av oppryddingen. Historisk eksponering er kontrollert separat og står åpen for videre vurdering; dagens filer er ikke bevis på ren historikk.
